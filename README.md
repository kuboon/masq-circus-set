# サーカス団 — マスカレードのキャラクターセット

天幕の下に集まった、はぐれ者の一座。十五人。

[**この一座でマスカレードする**](https://masq.kbn.one/new?set=https%3A%2F%2Fkuboon.github.io%2Fmasq-circus-set%2Fset.json)

[マスカレード](https://masq.kbn.one)は、参加者が顔と声を隠したまま話し、頃合いを見てみんな同時に素顔に戻る会議です。このリポジトリはそのキャラクターセットを一つ配っているだけで、masq 本体とは独立しています。誰でも同じやり方で自分の一座を配れます — [配布のしかた](https://github.com/kuboon/masquerade-meet/blob/main/docs/character-sets.md)。

## 中身

| ファイル | |
| --- | --- |
| `set.json` | 一座の名簿。これが配布物の本体 |
| `characters/*.png` | 十五人ぶんの絵 |
| `banner.png` | 一座の横長画像 |
| `index.html` | 人が見るページ。GitHub Pages で公開している |

`set.json` の中の画像パスはこの文書からの相対で書いてあるので、リポジトリごとどこに置いても壊れません。

## 直すとき

`id` は**変えてはいけません**。開いている最中のルームが `id` で誰が誰かを覚えているので、名前を変えると走っている会議が迷子になります。増やすのは安全です。

手元で確かめてから push してください。公開したセットが壊れていても、リンクを踏んだ人には何も表示されません — 標準のキャラクターで会議が開くだけで、気づけるのはチェッカを通したときだけです。

```
npx jsrex @kuboon/masquerade-character-set/cli set.json
```

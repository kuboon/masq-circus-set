# 絵

`set.json` が名指ししている十五枚。ファイル名は `id` と同じで、**`set.json` の
`id` を変えずにここのファイル名だけ変えると絵が消えます**。

- `ringmaster.png`
- `firebreather.png`

正方形。ロビーでは小さく並び、会議中はタイルいっぱいに出るので、顔が中央にあって
端が切れても困らない構図がよく持ちます。背景は透過でなくてかまいません — この一座は
どれも背景まで描かれた一枚絵です。

いまの十五枚は **138×138** です。渡された一覧シート（823×552 に十五人ぶん）から
切り出したもので、シートの解像度がそのまま上限になっています。masq 同梱のセットが
281×281 なので、会議中の大きなタイルではそのぶん眠く見えます。元の大きい絵があれば
差し替える価値があります。**`id` を変えずにファイルを置き換えるだけで済みます。**

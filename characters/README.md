# 絵

`set.json` が名指ししている十五枚。ファイル名は `id` と同じで、**`set.json` の
`id` を変えずにここのファイル名だけ変えると絵が消えます**。

- `lion.png`
- `ringmaster.png`
- `firebreather.png`
- `lighting.png`
- `magician.png`
- `knifethrower.png`
- `ticket.png`
- `cottoncandy.png`
- `popcorn.png`
- `juggler.png`
- `trapeze.png`
- `clown.png`
- `ropewalker.png`
- `balloon.png`
- `parrot.png`

正方形、256×256 以上、背景は透過。ロビーでは小さく並び、会議中はタイルいっぱいに
出るので、顔が中央にあって端が切れても困らない構図がよく持ちます。
